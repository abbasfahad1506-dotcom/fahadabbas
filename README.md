# Fahad Abbas Portfolio

Standalone Vite + React portfolio prepared for Vercel.

## Deploy to Vercel

1. Extract this ZIP.
2. Import the extracted folder into Vercel, or connect the folder to a Git repository.
3. Keep the default build settings. The included `vercel.json` uses `npm run build` and publishes `dist`.

## Run locally

```bash
npm install
npm run dev
```

The portfolio is static and does not require environment variables or a database.
